# Dott. Giovanni Crapanzano — Endocrinologo

Sito professionale in italiano, realizzato in HTML e CSS standard, senza dipendenze da ChatGPT o Sites.

## Contenuti

- Home con ritratto professionale e curriculum.
- Competenze: tiroide, diabete, trattamento dell'obesità, endocrinologia ginecologica, andrologia, ecografia tiroidea, surrene, ipofisi, calcio e paratiroidi, alterazioni del metabolismo.
- Prestazioni: valutazione specialistica ed ecografia della tiroide.
- Pagina Contatti separata, raggiungibile dal menu. Sedi Villa Gioia e S-Medical Group Sora, con indirizzi, mappe, telefoni e siti ufficiali anche nella home.

## Aprire e modificare il sito

Aprire `index.html` con un browser. Non servono installazioni o compilazione.

| File | Contenuto |
| --- | --- |
| `index.html` | Home, curriculum, competenze e prestazioni |
| `contatti.html` | Pagina Contatti |
| `style.css` | Stili e adattamento a telefono e computer |
| `ritratto-medico.png` | Ritratto fornito dal titolare |

Per cambiare i testi, modificare i file HTML. Per cambiare l'aspetto, modificare `style.css`. I pulsanti di appuntamento avviano una chiamata al numero indicato; non è presente un sistema di prenotazione online.

## Pubblicazione

Caricare questi file mantenendoli nella stessa cartella su un hosting per siti statici. La pubblicazione può essere configurata separatamente anche su GitHub Pages, dove disponibile per il proprio account e la visibilità della repository.

La creazione della repository non pubblica automaticamente il sito. Questa versione include le modifiche più recenti dell'anteprima locale, anche quelle non ancora pubblicate su Sites.

## Versione WordPress

Questa repository contiene il sito statico aggiornato. Il precedente pacchetto per Local/WordPress è un'esportazione separata e non contiene le ultime modifiche al curriculum e al ritratto.
